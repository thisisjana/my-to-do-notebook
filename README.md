
# My To-Do Notebook

A simple and accessible task management web application designed with a clean paper-notebook inspired interface. It allows users to create, manage, search, filter, and track their daily tasks in one place.

## Features

- Add, edit, and delete tasks
- Mark tasks as completed or active
- Search tasks by title
- Filter tasks by All, Active, and Completed
- Clear completed tasks
- Persistent task storage using LocalStorage
- Responsive design for different screen sizes
- Keyboard-friendly and accessible interface
- Notebook-inspired user interface

## Tech Stack

- HTML5
- CSS3
- JavaScript
- LocalStorage API
